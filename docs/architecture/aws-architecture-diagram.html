Genlogs — AWS Service Architecture (Point 2)

Same pipeline as the logical component diagram, redrawn to name the actual AWS service at every hop. Color marks the AWS service category; dashed edges mark points outside AWS control (cameras, the SAFER API) or failure/retry paths.

How this differs from the logical component diagram in docs/architecture/platform-architecture.md: that diagram names stages and responsibilities; this one commits to a specific AWS service per box so it can be handed to whoever writes the Terraform/CDK later. Swapping a service (e.g. Snowflake instead of Redshift, or SQS FIFO instead of standard) only changes a box label and its category color here — the stage boundaries and arrows stay the same.
